# Практична робота №2 — Основи CSS

Оформлення багатосторінкового сайту **Ferrari Fan Page** засобами CSS.

## Що стилізовано

- **Дизайн-система:** палітра у CSS-змінних (`:root`), `box-sizing: border-box`, базові стилі `body`, клас `.container` для центрування контенту.
- **Шапка, навігація, підвал:** темна шапка з червоною лінією, горизонтальне меню на **Flexbox**, стани посилань `normal / hover / active`, підвал у єдиному стилі.
- **index.html:** ієрархія заголовків, читабельні списки, картка-акцент (`.card`), адаптивне `figure`/зображення з тінню, оформлена таблиця (контрастний заголовок, чергування рядків через `:nth-child`).
- **about.html:** текстовий блок-картка, відео й аудіо у відокремлених картках, `video` шириною 100% з `max-width`, дві медіакартки поруч на **Flexbox** (`.two-column`).
- **contact.html:** форма в картці, оформлені `label / input / select / textarea / fieldset / legend / radio / checkbox / button`, стани `:hover` для кнопки та `:focus` для полів.
- **Адаптивність:** `responsive.css` з media queries (768px і 420px) — меню стає вертикальним, колонки складаються, відступи зменшуються, нічого не виходить за межі екрана.

## Структура

```
lab02-css/
├─ index.html
├─ pages/
│  ├─ about.html
│  └─ contact.html
├─ assets/
│  ├─ img/
│  └─ media/        (відео + аудіо)
├─ styles/
│  ├─ style.css      (основні стилі)
│  └─ responsive.css (адаптивність)
└─ README.md
```

## Як запустити

Відкрити `index.html` у браузері або через розширення **Live Server** у VS Code.
Перевірено у двох режимах: desktop і mobile (DevTools → Toggle device toolbar).

## Технічні примітки

- Вбудовані стилі через `style="..."` не використовуються — усе винесено у зовнішні файли.
- `responsive.css` підключається після `style.css`, щоб його правила могли перевизначати базові.
- Зображення на головній підвантажується із зовнішнього URL.
