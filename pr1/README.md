Проєкт pr1 містить простий **конвертер температур** на JavaScript 

## Як запустити

1. Встановіть [Node.js](https://nodejs.org/).
2. Клонуйте репозиторій та перейдіть у папку:
   ```bash
   git clone <URL_репозиторію>
   cd pr1-git-basics
   ```
3. Запустіть програму:
   ```bash
   node src/main.js
   ```

Очікуваний вивід:
```
25°C = 77 °F
98.6°F = 37.0 °C
```

## Функції

- `celsiusToFahrenheit(c)` — переводить градуси Цельсія у Фаренгейти.
- `fahrenheitToCelsius(f)` — переводить градуси Фаренгейта у Цельсії.
- `convert(value, unit)` — універсальна функція з перевіркою вхідних даних (`unit`: `"C"` або `"F"`).
