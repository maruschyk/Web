# Практична робота №7–8 — JavaScript для Ferrari Fan Page

Додавання клієнтської логіки на JavaScript до готового HTML/CSS-сайту.
Скрипти підключені зовнішніми файлами через `defer`, без inline-обробників.

## Реалізовані функції (10 обов'язкових)

1. **Структура коду** — папка `js/` з файлами `main.js`, `ui.js`, `contact.js`; код розбитий на функції ініціалізації, кожна перевіряє наявність елементів.
2. **Активна навігація** — поточна сторінка підсвічується класом `.is-active` (одна функція для всіх сторінок).
3. **Мобільне меню** — кнопка-бургер відкриває/закриває меню, змінює `aria-expanded`, автозакриття після кліку по пункту.
4. **Перемикач теми** — клас `theme-dark` на `<body>`, вибір зберігається в `localStorage` (`siteTheme`) і відновлюється після перезавантаження.
5. **Кнопка «вгору» + рік** — кнопка з'являється після прокручування, плавний скрол; рік у футері підставляється через JS.
6. **Акордеон** — блок «Часті запитання» з розгортанням/згортанням (видимий лише активний пункт).
7. **Фільтр** — каталог моделей фільтрується за категорією (усі / дорожні / гоночні / гібриди) через атрибут `hidden`, з empty-state.
8. **Модальне вікно** — деталі моделі та збільшення зображення (lightbox); закриття кнопкою, кліком по overlay та клавішею Esc.
9. **Покращення форми** — JS-валідація (ім'я ≥ 2 символів, email, непорожнє повідомлення, згода), текстові повідомлення про помилки, лічильник символів для textarea.
10. **Чернетка + submit** — дані форми зберігаються в `localStorage` (`contactDraft`) і відновлюються; при submit через `preventDefault()` + `FormData` показується блок-підтвердження, чернетка очищається.

## Додатково (зіркові завдання)

- **Б4. Обране** — зірочки на картках моделей, список у `localStorage` (`favoritesList`).
- **Б5. Очистити чернетку** — окрема кнопка з підтвердженням через власне модальне вікно (а не стандартний `confirm`).

## Як запустити

Відкрити `index.html` у браузері або через **Live Server** у VS Code.
Перевірено: у консолі браузера немає помилок, усі механіки працюють повторно.

## Як перевірити ключові сценарії

- **Тема:** перемкнути /☀ у шапці, оновити сторінку — тема збережеться.
- **Чернетка:** почати заповнювати форму, оновити сторінку — значення відновляться.
- **Submit:** надіслати валідну форму — з'явиться блок із введеними даними, чернетка очиститься.
- **Фільтр/обране:** відфільтрувати моделі, позначити зірочки, оновити сторінку — обране лишиться.
